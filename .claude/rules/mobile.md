# 모바일 앱(Flutter)

- 스펙 `docs/superpowers/specs/2026-10-03-mobile-app-design.md`, 계획 `docs/superpowers/plans/2026-10-03-mobile-app.md`, 런북 `docs/mobile-app.md`.
- **앱 표시 이름은 INNOCREW**(2026-10-22, 1.7.49): iOS `CFBundleDisplayName`, Android `android:label`, macOS `CFBundleName`·`CFBundleDisplayName`·About 메뉴, Windows 창 제목·Runner.rc FileDescription/ProductName·설치 프로그램 AppName·시작 메뉴 바로가기(옛 `INNOGRID.lnk`는 `[InstallDelete]`)·WinSparkle 앱 이름·토스트 appName, MaterialApp title. **바꾸지 않은 식별자**(업데이트·설정 호환): `INNOGRID.app`/`INNOGRID.exe`·설치 폴더·`PRODUCT_NAME`·번들 ID·URL 스킴 `innogrid`·`%APPDATA%\INNOGRID`·토스트 AUMID·메신저 mobileId·WinSparkle 회사명·iOS `CFBundleName`(ASC 앱 이름). 웹 사이트 제목(이노그리드)은 별개.
- 코드는 저장소 루트 `mobile/`(frontend와 같은 레벨). Flutter 3.47.7 stable(로컬·Windows 빌드 워크플로; 서명 워크플로 `windows-signed.yml`은 3.44.0으로 보류 중), Android 8+/iOS 15+, 번들 ID `com.innogrid.playground`, 딥링크 `innogrid://login-callback`. 의존성은 pubspec의 24개(flutter SDK 제외) + dev `flutter_launcher_icons`: 상태·라우팅 `flutter_riverpod`·`go_router`, 백엔드 `supabase_flutter`·`http`, WebView `webview_flutter`·`webview_flutter_wkwebview`·`webview_flutter_android`·`flutter_inappwebview_windows`·`flutter_inappwebview_platform_interface`(Windows WebView2), 저장 `shared_preferences`·`flutter_secure_storage`(아마란스 자동 로그인 — 2026-10-04)·`path_provider`(메일 색인), 서명 `crypto`, 메신저 `pointycastle`(P076 로그인 AES-256-CBC — 2026-10-21)·`mqtt_client`(메신저 실시간 대화·접속 상태 — 2026-10-21), 음성 `speech_to_text`·`flutter_tts`(2026-10-05 비서), 알림 `flutter_local_notifications`(데스크탑 메신저 멘션·새 대화·통합 알림 — 2026-10-10, Android는 core library desugaring 필요), 기타 `url_launcher`·`geolocator`·`file_picker`(이노봇 첨부)·`html`(메일 본문)·`flutter_markdown_plus`(이노봇 답 — 2026-10-15)·`workmanager`(잠금 화면 브리핑 백그라운드 갱신 — 2026-10-19) — 추가는 스펙 변경으로. SDK 패키지 `flutter_localizations`(기본 위젯 문구 한국어, 2026-10-20)는 개수에 넣지 않는다. 앱 전체 글자 선택·복사는 `main.dart` `SelectAllText`(builder 자리의 전용 Overlay + SelectionArea, 이노봇 레이어는 밖). 자동 새로고침(실시간·폴링) 화면은 새로고침 중에도 기존 내용을 유지해야 선택이 안 풀린다 — FutureBuilder 로딩 표시는 `waiting && !snap.hasData`일 때만(1.7.45, 메신저 화면 전체). `setState(() => _future = …)` 화살표는 Future를 돌려줘 디버그 단언에 걸리니 블록으로. 아마란스 화면은 `BrandHeader(onRefresh:)` 새로고침 버튼(데스크톱은 당겨서 새로고침 불가). 데스크톱 이노봇은 떠 있는 창(`lib/assistant/assistant_window.dart` — builder Stack의 전용 Overlay `assistantWindowOverlay`, 머리글 끌기·위치 기억 `innobot.window.pos`, 창 안 Navigator·SelectionArea), 휴대폰은 아래 시트.
- 하이브리드: 로그인·탭·뭐 먹지·사다리·커피 타임은 네이티브, 나머지는 WebView(`lib/web/`). 네이티브 API 호출은 `lib/api/client.dart`만 통해서(Bearer, 401 갱신 재시도 1회). WebView 뒤로 가기: Android는 가로챈 첫 내비게이션(`/login`)을 히스토리에 남기므로 `canGoBack()`만 믿지 말고, 뒤로 간 직후 `onPageStarted`가 세션 시작점(`isSessionBoundary`)이면 화면을 닫는다(`goBack`은 `onNavigationRequest`를 안 거친다).
- 서버: `/api/*`는 `Authorization: Bearer`도 받는다(`createServerSupabase`·proxy 분기 — 진입점 `frontend/src/proxy.ts`). `POST /api/mobile/login`(로그인 기록·역할·권한), `POST /api/mobile/web-token`(WebView용 일회용 magiclink 토큰), `/auth/mobile`(토큰 → 쿠키 세션 → next). WebView는 앱 세션을 복사하지 않는다(리프레시 회전 충돌).
- 토큰·세션 값은 로그·감사 detail·문서에 남기지 않는다. 감사 카테고리 `mobile`.
- 디자인: 토큰은 `lib/app/theme.dart`의 `Brand`, 공용 위젯은 `lib/app/brand.dart`(BrandHeader·BrandLogo·SquareIconButton·InitialBadge·PrimaryCta·GridBackdrop) — 새 화면은 이걸 쓰고 색을 직접 박지 않는다. **다크모드(2026-10-21, 1.7.35)**: `Brand`의 구조색(navy·ground·surface·line·hairline·fill·muted·faint·blueTint)은 밝기별 getter(`Brand.brightness`로 분기, const 아님 — `const TextStyle(color: Brand.navy)`는 const를 뗀다), 브랜드 색(blue·botViolet·sky·danger·success·cardBadge·tints)은 const 고정. **navy는 글자색**이라 다크에서 밝게 뒤집히므로 "짙은 배경"으로 쓰던 navy는 `Brand.hero`(두 밝기 모두 짙음, 흰 글자)로, 흰색 표면 바탕은 `Colors.white` 대신 `Brand.surface`로 쓴다. `appTheme(brightness:)`가 라이트·다크 두 벌을 만들고 MaterialApp builder가 활성 밝기를 `Brand.brightness`에 반영(네이티브 화면이 읽는 토큰 일치). 설정은 `themeModeProvider`(`lib/app/theme_mode.dart`, SharedPreferences `theme_mode`, 기본 시스템) + 더보기 '화면 테마' 세그먼트. 라이트는 hero=기존 navy·surface=흰색이라 픽셀 동일(골든 영향 없음). 로고는 `assets/brand/*.png`(원본 frontend/public/logo.svg, 재생성 방법은 런북 §디자인). 시안: Claude Design 캔버스 "이노그리드 앱 디자인". AnimationController 등 Ticker는 `late final` 지연 생성 금지(initState에서 생성).
- 하단 바(`lib/app/tab_shell.dart`): 홈(`/home`, 웰컴 — 인사·오늘의 한 줄·바로 가기·사내 서비스) · 그룹 일상/AI/업무(웹 2단 메뉴의 1단, `catalog.dart`의 `pageGroups`·`visibleGroups` — 볼 페이지가 없는 그룹은 숨김) · 더보기(계정·관리). 그룹을 누르면 하위 메뉴가 바 위에 **평범한 줄**(`menu_layout.dart` `rowLayout` 순수 함수 — 가로 중앙 정렬, 한 줄 개수는 폭에 따라 `max(5, 폭÷78)`개(폰 390은 5개·셀 78, 데스크톱 창은 한 줄), 셀 폭은 `min(폭÷5, 96, 폭÷가장 긴 줄)`, 넘치면 줄 균등 분배(남는 항목은 아래 줄부터), 맨 아래 줄 원 중심은 바 위 72px·줄 간격 90; 2026-10-10 부채꼴을 걷어냄, 2026-10-11 폭 적응)로 펼쳐진다 — 항목은 제자리에서 바 쪽에서 떠오르며 항목마다 60ms 시간차(`FanMenu.interval`, 윗줄 왼→오 순), 접힘은 reverse 역순. 네이티브 화면(뭐 먹지 1·사다리 2·커피 타임 3)은 셸 브랜치(`nativeBranch`), 나머지는 `/web`. 라우트 브랜치는 그대로 5개(home·food·ladder·team·more). 하단 바는 바깥 `ShellRoute`(`TabShell(child:)`)라 웹·아마란스·Dooray 화면(push)에도 남는다 — 탭 브랜치 셸은 `TabShell.attach`로 넘기고, 현재 탭은 맨 위 경로(`branchOf`, 탭 밖이면 마지막 탭)로 정한다(2026-10-20). 하위 메뉴 항목을 누르면 `_closeNow`로 애니메이션 없이 접는다. 격언은 `lib/features/home/quotes.dart`(출처 확실한 것만), 공휴일은 `greeting.dart`의 양력 고정 목록.
- 아마란스 연동: `lib/gw/`(스펙 2026-10-04). GW 호출은 `GwClient.call/callForm`만 지나고, 토큰·세션 값·메일 제목은 로그·메시지에 찍지 않는다. 쓰기는 출퇴근 기록(확인 다이얼로그·중복 가드·read-back) + 비서 확인 카드를 거친 작업뿐, 메일 본문(`mail002A01`)은 비서가 사용자 요청으로 읽을 때만(같은 요청의 목록·검색 muid, 5통). 서버 값은 `asStr/asBool/asInt`로만 읽고 메일함 seq는 상수 금지. 엔드포인트 출처 inno-creed(github.com/zilhak/inno-creed `docs/api-reference.md`). 하단 바 그룹 "아마란스"는 `catalog.dart` `appPages`(웹 카탈로그와 분리). 자동 로그인 비밀번호는 `flutter_secure_storage`에만(shared_preferences 금지), 로그인 페이지 JS는 `gw_login_js.dart`에 모은다. 게시판 `ViewPost`는 조회수를 올리므로 사용자가 글을 눌렀을 때만 부른다(목록 프리뷰로 미리 보이지 않게 자동 호출 금지). 메일 검색은 기기 안 색인(`mail_index.dart` 순수 Dart·`mail_indexer.dart` 수집, 앱 지원 폴더 JSON)으로 하며 **안 읽은 메일 본문은 색인하려고 열지 않는다**(읽음 처리 부작용) — 런북 `docs/mobile-app.md` §메일 검색.
- 배포(스펙 2026-10-04-mobile-release): 버전 출처는 `pubspec.yaml` `version: X.Y.Z+N` 하나 — 코드는 `Config.appVersion/appBuild`(`--dart-define`, 기본 `dev`/0 = 업데이트 확인 안 함). 릴리스는 `mobile/scripts/release-mobile.sh`로만(스토리지·`settings.mobile_release` 수동 편집 금지). Google Play 내부 테스트는 `release-mobile.sh android|all`이 AAB를 빌드해 내부 테스트 트랙에 자동 출시(`play-upload.py`, 서비스 계정 키 `PLAY_SERVICE_ACCOUNT_JSON` — 없으면 Android 릴리스를 시작하지 않음, 재시도 `release-mobile.sh play`). 앱 서명 키는 Google 생성 키. **Android 배포는 Play 내부 테스트로만**(2026-10-22 APK 직접 설치 중단 — 웹 `/apps`·업데이트 버튼은 내부 테스트 참여 링크, 스토리지 universal APK·SharePoint 사본은 릴리스 백업용). 로컬 키 APK 배포 금지, `docs/play-console-guide.md` §6-B. `settings.mobile_release`는 플랫폼별 블록(`android`/`ios`) JSON, 읽기는 `GET /api/mobile/release`(user 이상, APK 600초 서명 URL). 웹 `/apps`는 카탈로그에 있지만 앱 Dart 카탈로그 `pages`에는 넣지 않는다. 웹 홈 설치 안내 카드(`frontend/src/components/home/DesktopAppCard.tsx`, `GET /api/desktop/presence`)는 `login_history`의 앱 User-Agent `InnogridApp/<ver> (<defaultTargetPlatform.name>) InnogridBuild/<n>`로 데스크톱 앱 로그인 여부를 판단한다 — `Config.userAgent` 형식을 바꾸면 `lib/desktop/presence.ts`의 `appPlatform`도 함께(런북 §배포 "웹 홈 설치 안내 카드"). 아이콘은 이노봇 캐릭터 + 바탕 `#6268FF`(SECloudit BI "iT" 색, `Brand.botViolet`과 같음, 2026-10-05) — 앱 안 이노봇 버튼도 같은 바탕. `key.properties`·`*.jks`·`.env.release`는 gitignore, 비밀은 로그·문서에 남기지 않는다.
- 홈 브리핑(스펙 2026-10-04-mobile-briefing): 순수 로직은 `lib/briefing/briefing_model.dart`에만(위젯·네트워크 금지), 수집은 소스별 try/catch로 독립. Claude에는 `summaryPayload`(제목·이름·시각, 목록 ≤8, 문자열 ≤120)만 보내고 본문은 절대 넣지 않는다. 서버 `POST /api/mobile/briefing`은 payload를 저장·로그하지 않고 감사엔 건수만. 설정 `mobile_briefing_llm`(빈 값/`on`/`off`). Teams 멘션은 `GET /api/teams/mentions`(본문 전달만, 저장 금지). 아마란스 메신저 **멘션** 알림은 `/event/event02A01`(eventType TALK, `lib/gw/talk_alerts.dart` — 일반 채팅은 그룹웨어 알림에 없음), 데스크탑은 `talk_notifications.dart`가 60초 폴링 → OS 알림(누르면 `messenger_open.dart`: macOS `open -b com.douzone.amaranth10beta`, 모바일 `Amaranth10://` — 대화방 딥링크 없음).
- 잠금 화면 브리핑(스펙 2026-10-19-live-activity-briefing): 순수 로직 `lib/briefing/live_briefing.dart`, 플랫폼 `live_activity.dart`(iOS 채널 `innogrid/live_activity`·Android 상시 알림), 백그라운드 `live_background.dart`(아마란스만 — Supabase 세션 금지), iOS 확장 `ios/BriefingLiveActivity/`. 잠금 화면은 회의(지금 − 10분 이후 시작)·결재·메일 각 2줄, 전체 5줄 + 건수 줄. 메일은 제목·보낸 사람만(본문 금지).
- 비서 이노봇(스펙 2026-10-05-mobile-assistant): 도구 등급은 앱 `assistant_tools.dart`와 서버 `lib/assistant/tools.ts`가 같은 38개 이름을 고정(양쪽 테스트, Teams·Confluence·SharePoint는 서버 실행 `serverToolNames`). 우리 앱 기능 도구(Jira·인사부고·뭐 먹지·PPT, 서버 `lib/assistant/feature-tools.ts`)는 서버 전용이라 앱 표에 없다 — 앱은 서버가 준 등급(`PendingCall.tier`)과 카드 줄(`card`)로 확인 카드를 그린다. 쓰기는 앱 확인 카드 없이 실행하지 않고, 카드는 모델이 쓴 라벨이 아니라 조회한 실제 대상으로 만든다. 서버가 대화를 저장한다(`/api/chat/turn`, 앱은 `client:"app"` — needs_action을 받아 앱 도구 실행·확인 카드 후 actions로 회신, 결과는 요약만 저장, 감사엔 도구 이름·토큰·가린 건수). 선택지 안의 서버 쓰기와 카드용 대상 확인은 기존 `/api/assistant/execute`. 구버전(1.7.0 미만) 앱의 `/api/assistant/turn`은 업데이트 안내(426)만 돌려준다 — 보급이 끝나면 지운다.
